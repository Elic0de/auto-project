# 就活向け README

このリポジトリは、リアルタイム対戦型カードゲームのサンプルプロジェクトです。Vue.js と Phaser を用いたクライアントと、Colyseus(Express + TypeScript) を用いたサーバーで構成されています。就職活動時のポートフォリオとして、本プロジェクトの概要やセットアップ方法をまとめています。

## 特徴

- **リアルタイム対戦**: Colyseus を利用し、2 人のプレイヤーがリアルタイムで対戦できます。
- **カードベースの戦闘**: スキルカードと条件カードを組み合わせて戦う戦略性の高いゲームです。
- **ターン制バトル**: 10 ターンで 1 ラウンド、5 ラウンド先取で勝敗が決まります。
- **アニメーション演出**: Phaser によるリッチなアニメーションでゲームを盛り上げます。

## 技術スタック

- **フロントエンド**: Vue.js 3, Phaser, Pinia, Vite
- **バックエンド**: Colyseus, TypeScript, Express
- **その他ツール**: Prettier, npm Workspaces

## セットアップ

1. 依存関係のインストール

   ```bash
   npm install
   ```

2. 開発サーバーの起動

   ```bash
   npm run dev
   ```

   クライアントとサーバーが同時に起動します。

3. ビルド

   ```bash
   npm run build
   ```
